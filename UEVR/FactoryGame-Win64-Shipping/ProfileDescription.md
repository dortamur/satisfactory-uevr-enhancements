## UEVR Enhancements mod installation

- [Download](https://smm.ficsit.app/) and install the [Satisfactory Mod Manager (SMM) app](https://ficsit.app/)
- Run Satisfactory Mod Manager, search for "UEVR Enhancements" and select the download button to install the mod, along with its dependencies

## Starting Satisfactory VR

- Run Satisfactory, and load into your saved game (or start a new game). You should see "Ready for UEVR Injection..." up the top-left if the mod is installed correctly
- Make sure your VR headset is connected and ready
- Select "Inject into running game" in UEVR Easy Injector

## Notes:
- You can now Inject while still in the main menu, but if you have issues with games crashing on loading, it is recommended to inject after loading your save game
- Check the [Troubleshooting page](https://github.com/dortamur/satisfactory-uevr-enhancements/wiki/Troubleshooting) if you're having problems with the setup, and for other recommended settings for UEVR and Satisfactory
- For further information, see the [Wiki page for getting started](https://github.com/dortamur/satisfactory-uevr-enhancements/wiki/Getting-Started)
